# Aolong Sun — Personal Portfolio

A bilingual professional portfolio for Aolong Sun, a Statistics PhD student at Virginia Tech. The site presents verified education and experience through an evidence-oriented structure focused on problems, data, methods, and outcomes.

Live site: [https://aolongsun.github.io/](https://aolongsun.github.io/)

## Highlights

- English-first interface with complete Chinese localization
- Responsive React and TypeScript implementation
- Fixed navigation and language-independent desktop Hero geometry
- Interactive experience browser with keyboard support
- Reduced-motion support and static media fallback
- Static architecture compatible with GitHub Pages

## Local development

Requirements: Node.js 18 or newer and npm 9 or newer.

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Content and privacy

Public biographical content is maintained in `content/`. Original resumes, unfiltered photos, private source material, credentials, and confidential data are intentionally excluded from this repository.

## Status

Version 0.1 is published through GitHub Pages. Pushes to `main` automatically install dependencies, build the Vite application, and deploy the generated `dist/` directory.
